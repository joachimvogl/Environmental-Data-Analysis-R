# Environmental Data Analysis in R

Statistical modeling of natural resource and environmental data in R: descriptive statistics, distributions, correlation, linear regression, and trend analysis using ecological datasets

## Projects

| Project | Description | Methods |
|---------|-------------|---------|
| [Lake Ice Duration & Winter Air Temperature](lake-ice-duration-regression/) | Tests whether warmer winters shorten ice cover on two Wisconsin lakes (Mendota and Monona) over 152 winters, 1869–2020 | Spearman correlation, simple linear regression |
| [Palmer Penguins Species Comparison](palmer-penguins-summary-statistics/) | Compares bill and flipper size across Adélie, Chinstrap, and Gentoo penguins (n = 344) from the Palmer Archipelago, Antarctica, 2007–2009 | Descriptive statistics, histograms, scatterplots, correlation |

## Tools

R / RStudio · `tidyverse` · `ggplot2` · `rstatix` · `lterdatasampler` · `palmerpenguins` · `knitr`
